# First 5 Alameda CEE Demo by Focus

This is a demo repo using our existing starter kit.

It includes:
* Simple authentication (email and password)
* Demo mode (login by role, reset data)
* AI / LLM integration ready: chat support for users
* Design system: USWDS
* API documentation (Swagger)
* AI/LLM coding assistance documentation (AGENTS.md file)
* Tests: API and browser tests using vitest
* CI (Github actions)
* Simple deploy to start (Kamal + Hetzner + Cloudflare), replace with infrastructure as code scripts when required
