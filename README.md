# Typescript Fullstack Template

This is a batteries included typescript fullstack template for the government digital services context. We are using a monorepo approach with separate backend and frontend top level folders.

It includes:
* Simple authentication (email and password)
* Demo mode (login by role, reset data)
* Example flow: leave benefit application and adjudication
* Example AI / LLM integration: chat assistant for leave applicants, with custom tools
* Design system: USWDS
* API documentation (Swagger)
* CI (Github actions)
* Simple deploy (Kamal + Hetzner + Cloudflare)
* AI/LLM coding assistance documentation (AGENTS.md files)
* Tests: API and browser tests using vitest

Coming soon
* IaC deploy (Terraform)
